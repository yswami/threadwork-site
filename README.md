# Threadwork vision website

Public website: https://yswami.github.io/threadwork-site/

A static, mobile-first website for Threadwork's vision, genuine prototype evidence, and an early-access signup. The application repository remains separate and private.

## Run locally

`python3 -m http.server 4180`

Open http://127.0.0.1:4180/ . No dependencies or build step.

## Publish

GitHub Pages serves the root of the `main` branch. A `.nojekyll` file keeps this a plain static site.

## Signup and privacy

The CTA opens a published Google Form. Responses stay in the owner's Google Forms account, not in this repository. Email and contact consent are required. Use case and phone platform are optional. No sign-in requirement, public results summary, advertising, or site analytics has been enabled. GitHub and Google operate their respective services and may process service data.

The website does not claim a shipping app, production readiness, user adoption, automatic WhatsApp posting, or complete iPhone validation. The recorded Android emulator demo contains generation failures and repairs. All displayed activity data is fictional test data.

## Assets

Screenshots and the silent video come from the actual prototype recording. Voice narration, private source code, credentials, local memory databases, and signup responses are not part of this public repository.
